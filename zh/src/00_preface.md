# 前言

欢迎阅读《Goose 编程》（*Programming in Goose*）——这是一本实用指南，旨在教你如何在无需堆分配器、垃圾回收器或生命周期标注的情况下，编写高性能、内存安全的系统软件。

乍看之下，Goose 会让人倍感亲切：它借鉴了 C 与 Rust 的花括号、`let`、`fn`、`struct` 和 `match` 语法。然而在其底层，它对内存采用了截然不同的处理方式：每个动态值都内联存放在由编译器管理的**数据栈**上，扩容只需一次指针递增，而释放也只是在离开作用域时执行一次指针存储操作。

先来领略一下 Goose 的风采——下面这段代码在一个连续数组内部直接内联构造了五个字符串，全程零堆分配：

```goose
fn main() {
    var words: u8[][>..] = [];
    for i in 5 {
        words.push(str("word", i));
    }
    print(words);
}
```

```
["word0", "word1", "word2", "word3", "word4"]
```

## 本书组织结构

- **第一部分（第 1–4 章）**：核心语法、大小类别、数据栈、数组与内联字符串。
- **第二部分（第 5–8 章）**：切片、引用、可选引用、推断式生命周期、双模式枚举、根结构体（`root struct`）与标准库对象池（`slot_pool` 槽位池 / `slice_pool` 切片池）。
- **第三部分（第 9–13 章）**：泛型、静态函数值、`const for`、基于 `return … from` 的错误处理、递归、相对引用与受验证序列化。
- **第四部分（第 14–17 章）**：无共享线程、双向 C 语言互操作、包与工具链，以及标准库导览。
- **第五部分（第 18–19 章）**：索引类型、越界检查消除、无检查函数（`checkfree fn`）、`simd fn` 与性能工程。
- **第六部分（第 20–23 章）**：三个端到端综合实战项目，以及 Goose 编译器内部架构导览。
- **附录 A–D**：速查手册、C++/Rust 迁移指南、编译器诊断信息实用指南，以及当前限制说明。

## 约定与验证

本书中的每一段 Goose 代码示例都会通过 Goose 编译器自动校验（`scripts/check_examples.py --run`）。紧跟在完整程序之后的输出块展示的正是该程序运行产生的确切输出。
